# 生于沙海

一个基于物理模型的真实世界生存游戏。**第一幕：沙漠** —— 主人公在日出前醒来在一片夏季沙漠中，带着一只水囊和一张塑料布，要在脱水和中暑之前找到十几公里外的绿洲，再顺着线索找到被沙埋住的地下城入口。走进地下城，第一幕结束。

## 运行

```bash
npm start        # 等价于 python3 -m http.server 8000
# 打开 http://localhost:8000
npm test         # 物理模型与游戏流程的测试（Node 18+，无依赖）
```

页面使用 ES 模块，需要通过 HTTP 访问，直接双击 `index.html` 不行。

## 物理模型（`src/physics.js`）

所有量都用真实单位，每个行动按 1 分钟步长积分。

| 部分 | 模型 |
| --- | --- |
| 太阳 | 纬度 24°N、夏至前后的太阳高度角；Kasten-Young 大气质量 + 晴空透过率得到直射、散射和总辐照度 |
| 气温 | 05:30 最低（约 19°C），15:00 最高（约 43°C），每天有 ±2°C 的随机偏移；沙面温度随日照升到 60°C 以上，夜间低于气温 |
| 湿度 | 水汽压恒定（露点约 5.5°C），相对湿度随气温在 10%–40% 间变化 |
| 身体 | 体表面积（DuBois）、基础代谢（Mifflin-St Jeor）、体脂（Deurenberg）由性别、年龄、身高、体重算出 |
| 热平衡 | 代谢产热 + 日照吸收 + 对流/长波辐射 − 汗液蒸发 = 储热；储热 ÷（体重 × 3470 J/kg·K）= 核心体温变化 |
| 出汗 | 由体温调节驱动，上限约 1.5 L/h；脱水超过 2% 后出汗能力下降，体温调定点每 1% 脱水上升 0.15°C |
| 失水 | 汗液 + 呼吸、皮肤扩散和最低尿量（约 1.2 L/天） |
| 寒冷 | 核心体温低于 36.6°C 开始寒战产热；血管收缩增大组织热阻 |
| 致死线 | 核心体温 ≥ 42°C 或 ≤ 29°C；失水 ≥ 体重的 15% |

参考量级：正午在太阳下静坐约失水 0.5 L/h，阴凉处约 0.25 L/h，正午步行约 0.9 L/h，夜间步行约 0.3 L/h。

## 玩法（`src/game.js`、`src/world.js`）

- 地图 41×41 km，每格 1 km，由“沙漠编号”确定性生成；绿洲在出生点 10–14 km 外，一条干河床从绿洲向外延伸。绿洲可以无限取水，还有椰枣。
- 黎明和黄昏，沙鸡会朝水源方向飞——这是找绿洲的主要线索。
- 行动：行走、休息、睡觉、喝水、搜索、在干河床挖水、挖遮阴沟、布置太阳能蒸馏器、割取多肉植物。
- 地形：沙丘视野远但走得慢、耗水多；岩石有阴凉，岩窝里偶尔有积水；干河床靠近绿洲的一段地下水很浅。

## 地下城入口

绿洲的水不是天然泉水，而是一条人工暗渠（坎儿井）引来的，暗渠的源头就是地下城。

- 入口在绿洲另一侧 6–8 km 外的一处岩壁下，外表和普通岩石露头一样。
- 从绿洲到入口，地面上每隔 2 km 有一口通风竖井，排成一条直线。
- 线索：在绿洲搜索能看到暗渠的走向；在竖井搜索能看到整条井线指向哪里；离入口 7 km 以内，黎明最冷时能看见地下暖湿空气冒出来凝成的一缕白雾。
- 竖井口吹出的是接近全年均温（约 31°C）的地下空气：白天在井口休息比别处凉，夜里比别处暖。井太深，取不到水。
- 到了入口所在的岩石要先“搜索”才能发现门楣，再花 2 小时清掉门前 1 m 的积沙，才能推门进去。

## 沙暴

- 多在 13–19 点起风，持续 2–5 小时，峰值风速 12–20 m/s；每天约 45% 的概率，头两天里保证至少一场。日程由沙漠编号决定。
- 到来前 45 分钟能看见沙墙，长时间的休息会被打断，留出时间找背风处。
- 物理效果：沙尘挡掉九成直射光（一部分变成散射光），气温降约 3°C，强风加大对流换热。
- 玩法效果：只能看见脚下，地图被遮住；步速减半，每走一格有一半概率走偏到垂直方向；不在背风处（岩石阴影或遮阴沟）会额外疲劳。
- 沙暴过后，别处挖的遮阴沟和渗水坑被流沙填平，蒸馏器里已凝的水报废。

## 夜间动物

| 动物 | 什么时候遇到 | 后果 |
| --- | --- | --- |
| 蝎子 | 夜里坐着或睡着时（岩石 4%/小时、干河床 3%、平原 1.5%、沙丘 0.5%）；任何时候搜索岩石有 6% | 2 小时内疼得睡不着，6 小时内代谢 +20% |
| 角蝰 | 夜里每走一格 2%（岩石、干河床 3%） | 65% 听到示警后绕开（多花 10 分钟）；35% 被咬：步速减半、代谢 +15%，持续 24 小时，并损失 0.3 L 体液 |
| 耳廓狐 | 21:00 和 02:00 醒着时偶尔出现 | 无害；在平原或沙丘上有时会刨出一株可食的多汁根茎 |
| 胡狼 | 23:00 醒着且离绿洲 9 km 以内 | 嚎叫声指出绿洲的方位 |

沙暴期间动物都不出现。
