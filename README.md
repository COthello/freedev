# 生于沙海

一个基于物理模型的真实世界生存游戏。

## 故事

公元 2226 年，距今两百年。地表环境变得无比严酷，已经养不活人。主人公要在地表活下来，找到地下世界的入口，进入并探索地下世界，最终发现这个世界真正的秘密。

- **第一幕 · 地表**（已完成）：主人公日出前在沙漠中醒来，带着一只水囊和一张塑料布。先在脱水和中暑之前找到十几公里外的绿洲，再顺着水的线索找到被沙埋住的入口，走进地下。
- **第二幕 · 深泉**（第一章已完成）：地下还有人，是一个繁荣的世界。主人公从闸口的检疫站开始，以“闸外来的人”的身份在城里找活干、认识人，直到落户成为居民。
- **秘密**（待设计）：目前只埋了伏笔——2098 年为什么封闸，档案馆闭架区里那箱和闸门同编号的卷宗。

地表上散落着旧时代的遗物（路面、太阳能板、路牌、河蚌壳），在平原和沙丘上“搜索”时偶尔能翻到。

## 运行

```bash
npm start        # 等价于 python3 -m http.server 8000
# 打开 http://localhost:8000
npm test         # 物理模型与游戏流程的测试（Node 18+，无依赖）
```

页面使用 ES 模块，需要通过 HTTP 访问，直接双击 `index.html` 不行。

## 像素风 3D 视角（`src/view3d.js`）

第一幕的画面是实时 3D 的第一人称视角，像素风格，用 three.js（r128，从 cdnjs 载入）渲染。

- **像素化**：画面横向只渲染 320 个像素，每个颜色通道压成 10 级色阶，级与级之间用 4×4 拜耳矩阵做有序抖动，再放大成大像素。
- **地形**：由地图格子生成连续的高度场：沙丘起伏、岩石台地、下切的干河床、绿洲洼地。一格（游戏里的 1 km）在画面里压缩成 60 m。
- **光和天**：太阳的位置、颜色、强弱，天空颜色，能见距离，都取自物理模型算出的太阳高度角和辐照度。太阳投下实时的影子；夜里有月亮和星空；地平线上有远山，高空有薄云；沙暴时是土黄色的浓雾和横飞的沙粒。
- **地面细节**：脚下四十米内按地形密度铺碎石和枯草（平原多石、干河床多草、沙丘几乎没有），全图另有零散的石块和灌木。
- **物体**：岩石、金合欢、绿洲的棕榈和水面、涵管口、竖井井圈、入口的断崖和闸门、遮阴沟、蒸馏器、渗水坑。
- **旧时代遗物**：沥青路面、太阳能板残架、路牌、骆驼骨架、倒伏的电杆、半堵砖墙，位置由沙漠编号决定。
- **夜间动物**：遇到耳廓狐、角蝰、蝎子时，它们会出现在面前。
- **视角**：走一格时相机平滑移过去并转向行进方向；拖动画面可以环顾四周；睡觉时躺下看天。
- 没有 WebGL 或载不到 three.js 时自动退回原来的 2D 画面。第二幕目前仍是 2D 剖面图。

## 物理模型（`src/physics.js`）

所有量都用真实单位，每个行动按 1 分钟步长积分。

| 部分 | 模型 |
| --- | --- |
| 太阳 | 纬度 24°N、夏至前后的太阳高度角；Kasten-Young 大气质量 + 晴空透过率得到直射、散射和总辐照度 |
| 气温 | 05:30 最低（约 19°C），15:00 最高（约 43°C），每天有 ±2°C 的随机偏移；沙面温度随日照升到 60°C 以上，夜间低于气温 |
| 湿度 | 水汽压恒定（露点约 5.5°C），相对湿度随气温在 10%–40% 间变化 |
| 身体 | 体表面积（DuBois）、基础代谢（Mifflin-St Jeor）、体脂（Deurenberg）由性别、年龄、身高、体重算出 |
| 热平衡 | 代谢产热 + 日照吸收 + 对流/长波辐射 − 汗液蒸发 = 储热；储热 ÷（体重 × 3470 J/kg·K）= 核心体温变化 |
| 出汗 | 由体温调节驱动，上限约 1.5 L/h；脱水超过 2% 后出汗能力下降，体温调定点每 1% 脱水上升 0.15°C |
| 失水 | 汗液 + 呼吸、皮肤扩散和最低尿量（约 1.2 L/天） |
| 寒冷 | 核心体温低于 36.6°C 开始寒战产热；血管收缩增大组织热阻 |
| 致死线 | 核心体温 ≥ 42°C 或 ≤ 29°C；失水 ≥ 体重的 15% |

参考量级：正午在太阳下静坐约失水 0.5 L/h，阴凉处约 0.25 L/h，正午步行约 0.9 L/h，夜间步行约 0.3 L/h。

## 玩法（`src/game.js`、`src/world.js`）

- 地图 41×41 km，每格 1 km，由“沙漠编号”确定性生成；绿洲在出生点 7–10 km 外，一条干河床从绿洲向外延伸。绿洲可以无限取水，还有椰枣。
- 黎明和黄昏，沙鸡会朝水源方向飞——这是找绿洲的主要线索。白天隔着 5 km（站在沙丘上 7 km）能直接看见绿洲的树。
- 行动面板上方有“提醒”：此刻赶路和歇着各失多少水、已知的方位线索、沙暴和身体的警告。每个方向的移动按钮都写着这一段要失多少水。
- 难度：宽松 4 L 水、动物和走偏概率 ×0.4；标准 3 L、×0.7；严酷 1.5 L、×1，且第一天就可能起沙暴。
- 体温到热衰竭（39.2°C）时，走路和重体力活都会自动停下。
- 行动：行走、休息、睡觉、喝水、搜索、在干河床挖水、挖遮阴沟、布置太阳能蒸馏器、割取多肉植物。
- 地形：沙丘视野远但走得慢、耗水多；岩石有阴凉，岩窝里偶尔有积水；干河床靠近绿洲的一段地下水很浅。

## 地下世界入口

绿洲的水不是天然泉水，而是从一条旧时代的混凝土涵洞里溢出来的，涵洞的另一头就是地下世界。

- 入口在绿洲另一侧 4–6 km 外的一处岩壁下。白天走到 3–5 km 以内能看出那片岩壁根部有一道笔直的暗影，地图上会标出来。
- 从绿洲到入口，地面上每隔 2 km 有一口通风竖井，排成一条直线。
- 线索：在绿洲搜索能看到暗渠的走向；在竖井搜索能看到整条井线指向哪里；离入口 7 km 以内，黎明最冷时能看见地下暖湿空气冒出来凝成的一缕白雾。
- 竖井口吹出的是接近全年均温（约 31°C）的地下空气：白天在井口休息比别处凉，夜里比别处暖。井太深，取不到水。
- 到了入口所在的岩石要先“搜索”才能发现闸门，再花 2 小时清掉门前 1 m 的积沙，才能转开手轮进去。

## 沙暴

- 多在 13–19 点起风，持续 2–5 小时，峰值风速 12–20 m/s；每天约 45% 的概率，头两天里保证至少一场。日程由沙漠编号决定。
- 到来前 45 分钟能看见沙墙，长时间的休息会被打断，留出时间找背风处。
- 物理效果：沙尘挡掉九成直射光（一部分变成散射光），气温降约 3°C，强风加大对流换热。
- 玩法效果：只能看见脚下，地图被遮住；步速减半，每走一格有一半概率走偏到垂直方向；不在背风处（岩石阴影或遮阴沟）会额外疲劳。
- 沙暴过后，别处挖的遮阴沟和渗水坑被流沙填平，蒸馏器里已凝的水报废。

## 夜间动物

| 动物 | 什么时候遇到 | 后果 |
| --- | --- | --- |
| 蝎子 | 夜里坐着或睡着时（岩石 4%/小时、干河床 3%、平原 1.5%、沙丘 0.5%）；任何时候搜索岩石有 6% | 2 小时内疼得睡不着，6 小时内代谢 +20% |
| 角蝰 | 夜里每走一格 2%（岩石、干河床 3%） | 65% 听到示警后绕开（多花 10 分钟）；35% 被咬：步速减半、代谢 +15%，持续 24 小时，并损失 0.3 L 体液 |
| 耳廓狐 | 21:00 和 02:00 醒着时偶尔出现 | 无害；在平原或沙丘上有时会刨出一株可食的多汁根茎 |
| 胡狼 | 23:00 醒着且离绿洲 9 km 以内 | 嚎叫声指出绿洲的方位 |

沙暴期间动物都不出现。

## 第二幕：地下城市“深泉”（`src/city.js`、`src/act2.js`）

2041 年建成的“深层避难与水源工程”第七号，2098 年封闸，现有 21,400 人。主角的身体仍由同一套热平衡模型驱动，只是环境换成了各区的室内气候。

**城市的收支**（每小时结算，界面上实时显示）：

| 系统 | 模型 |
| --- | --- |
| 电 | 地热 118 MW。最大的用户是光田的灯：78 MW，约合每人 3.6 kW；加上通风 17、水处理 6、生活 9–16 MW，白天几乎没有余量 |
| 粮 | 光田 04–22 点亮灯时才生长，满负荷产量比全城消耗（每人 2300 kcal/天）多 4%；缺电时按比例熄灯减产 |
| 水 | 含水层每小时补给 52 m³；用水回收率 96%；水库（9 万 m³）满了之后，多余的水以约 9 L/s 从溢流渠排到地表——这就是第一幕的绿洲 |
| 气 | 每人每天耗氧 0.84 kg，光田按产粮量折算产氧；中庭 CO₂ 随人流在 600–1200 ppm 间起伏 |
| 热 | 用掉的电和人的体热最终都要排出去（约 116 MW） |

每天有一件由沙漠编号决定的大事：热井检修（发电降到八成，光田轮流熄灯）、回水泵故障、收获日（饭便宜两成）、议事厅表决日。

**九个区域**，由浅到深：闸口（−35 m）、议事厅、中庭集市、学堂与医馆、环廊居住区、档案馆、光田（28°C、湿度 75%）、水厂（19°C）、热井（−860 m，39°C）。

**十四位居民**，各有职业、年龄和作息表（在哪个时段出现在哪个区，夜里回家睡觉）。每次交谈 15 分钟，越熟说得越深；其中四位熟了之后愿意作保。

**经济**：货币是“度”（1 度 = 1 kWh 配额）。

| 项目 | 度 |
| --- | --- |
| 检疫后的安置配额 | +40 |
| 光田采收（6 小时） | +30 |
| 水厂巡管（6 小时） | +36 |
| 热井巡检（4 小时，每干 40 分钟进冷却舱歇 20 分钟） | +60 |
| 把塑料布卖给旧货商 | +35 |
| 食堂一顿（约 900 kcal，价格随存粮浮动） | −8 |
| 豆饼（约 350 kcal） | −3 |
| 客栈铺位（至多睡 8 小时） | −12 |
| 医馆处理伤口 | −25 |
| 公共水龙头 | 免费 |

**第一章的目标**：落户。条件是干满三个工、有一位居民作保、本人到议事厅户籍处（8–18 点）办理。落户后可以进档案馆开架区，当前内容到此为止。
